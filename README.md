Your Planner – Smart Personal Finance Assistant
About the Project
Your Planner is an interactive web-based personal finance tool designed to help users track and optimize their monthly budget. Instead of manual savings tracking, the application takes the user's monthly salary and total expenses as input, automatically calculates the remaining balance and savings rate, and provides personalized financial advice and tips based on their spending habits.

Features
Smart Budget Breakdown: Instantly calculates the remaining balance and current savings percentage based on salary and expenses.

Financial Advice System: Evaluates the user's spending-to-savings ratio and delivers tailored financial feedback.

Responsive User Interface: Clean, user-friendly UI designed for seamless interaction.

Tech Stack
HTML5 – Structure and layout

CSS3 – Styling and design

Vanilla JavaScript – Core logic, budget calculations, and dynamic advice generation
